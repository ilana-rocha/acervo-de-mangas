O que é o Acervo de Mangás?

Eu desenvolvi esse projeto para facilitar a organização de uma coleção de mangás, reunindo os principais dados de cada título em um único sistema.

Problema

Manter informações de uma coleção apenas em anotações pode dificultar a consulta e a atualização dos dados.

Solução

O sistema permite cadastrar, visualizar, editar e excluir registros diretamente no banco de dados.

Público

Esse projeto é voltado para pessoas que gostam de mangás e desejam organizar e consultar seu próprio acervo de mangás.
